# Suno Master

수노(Suno) AI로 음악을 만들고 배포하기까지 — **당근모임**(부산 연제구 수노 자동화 & 프로듀싱 정기모임)에서 정리한 실전 전자책입니다.

## 보기

`index.html`을 열면 사이드바 목차형 전자책 리더가 실행됩니다.

- 📖 **본문 목차**: 14개 챕터 (프롬프트 작성 → 발매/유통)
- 🛠 **부록**: 점검표, 발매 체크리스트, 커뮤니티 가이드
- 테마 4종(페이퍼 웜 / 클래식 화이트 / 미드나잇 다크 / 로열 네이비), 글자 크기 조절, 완독률 추적 지원

## 배포

정적 HTML 단일 파일이라 GitHub Pages, Vercel 등 어디에나 바로 배포할 수 있습니다.
